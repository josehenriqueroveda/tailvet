# Tailvet - Veterinary Clinic Management System

Tailvet is a modern and intuitive web platform designed to streamline the daily operations of a veterinary clinic. Built with Next.js, React.js, and PostgreSQL, this application provides a comprehensive suite of tools for managing appointments, patient records, prescriptions, and more.

## ✨ Features

- **Secure Authentication**: A clean and secure login system for authorized users.

- **Appointment Management**: Easily schedule and track patient appointments, distinguishing between initial consultations and follow-ups.

- **Digital Prescriptions**: Create, manage, and archive digital prescriptions with detailed medication information and instructions.

- **Financial Control**: Track services rendered, manage payment statuses, and view total costs for each appointment.

- **Comprehensive Patient Records**: Maintain detailed records for each pet, including their owner's information.

- **Intuitive User Interface**: A clean and user-friendly interface designed for efficiency.

## 💻 Technologies Used

This project is built upon a modern and robust technology stack:

- **Frontend**:

  - Next.js - A React framework for building server-side rendered and static web applications.
  - React.js - A JavaScript library for building user interfaces.

- **Backend**:

  - Node.js - A JavaScript runtime environment.

- **Database**:

  - PostgreSQL - A powerful, open-source object-relational database system.

- **Styling**:
  - Tailwind CSS
